# Project GPT Design Assessment

This repository contains my submission for the **Project GPT Design Assessment**. It demonstrates both the theoretical design principles and the practical application of creating a focused, scoped, and well-structured Project GPT inside ChatGPT.

## Repository Structure

| File/Folder | Description |
| :--- | :--- |
| `assessment/` | Contains the completed written assessment covering Exercises 1–4. |
| `loom/` | Contains the link and description of the Loom video walkthrough. |
| `examples/` | Contains the sample input and output generated during the practical demonstration. |

## Assessment Overview

The assessment is divided into four key exercises:

1.  **Define Purpose:** Establishing a clear, focused primary task for the GPT (Bakery Customer Inquiry Assistant).
2.  **Define Role:** Crafting a specific role identity to guide the GPT's decision-making (Resume Consultant).
3.  **Define Scope & Input:** Setting explicit behavioral boundaries (SHOULD/SHOULD NOT) and a structured input format (Travel Itinerary GPT).
4.  **Define Output Format:** Designing a consistent, structured output to avoid unstructured walls of text (Feature Request -> Structured User Story).

## Practical Demonstration

The theoretical concepts from Exercise 3 and 4 were applied to create a functional **Travel Itinerary GPT** inside a ChatGPT Project. The practical demonstration uses a structured travel brief for Goa, India, to generate a day-by-day itinerary with clear assumptions and budget considerations.
